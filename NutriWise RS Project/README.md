# NutriWise — Nutrition Workspace

A responsive, single-page nutrition planner and diet plan recommender.

## Run locally
Open `index.html` in a modern web browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` (and this `README.md`) to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and the `/(root)` folder, then save.
6. After GitHub Pages finishes deploying, use the website URL shown in the Pages settings.

## Notes
- The website is a static HTML/CSS/JavaScript site; `index.html` is the entry point.
- Planner preferences and progress records are stored in the browser, so they are local to that browser/device and are not synced to an account.
- Nutrition values are estimates and should be checked against actual ingredients and serving sizes.
